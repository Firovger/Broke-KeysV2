# Broke Keys 🎹

Профессиональное приложение для отслеживания интервалов между нажатиями клавиш **A** и **D**.

## Как запустить у себя на компьютере:

1. **Установите Node.js**: Скачайте и установите с [nodejs.org](https://nodejs.org/).
2. **Скачайте код**: Распакуйте архив с проектом.
3. **Установите зависимости**:
   Откройте терминал в папке проекта и выполните:
   ```bash
   npm install
   ```
4. **Запустите приложение**:
   ```bash
   npm run dev
   ```
5. **Откройте в браузере**: Перейдите по адресу `http://localhost:3000`.

## Как сделать полноценное Desktop-приложение (.exe):

Чтобы приложение всегда было поверх других окон, его нужно обернуть в **Electron**. 

1. Установите Electron:
   ```bash
   npm install --save-dev electron
   ```
2. Создайте файл `main.js` (основной процесс Electron), указав в настройках окна:
   ```javascript
   alwaysOnTop: true,
   frame: false, // для "чистого" интерфейса снизу
   ```
3. Соберите проект:
   ```bash
   npm run build
   ```

## Возможности:
- 🕒 Отслеживание интервала в мс (настраиваемый таргет).
- 🔊 Звуковая обратная связь (разные звуки для попадания и промаха).
- 🎨 Динамическая смена цвета интерфейса при промахе (красный).
- 📉 Компактный режим (только нижняя панель).
- ⚙️ Настройка "Допуска" (Tolerance) для фильтрации дребезга клавиш.
